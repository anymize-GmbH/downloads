# anymize Downloads

Offizielle Downloads und Prüfsummen für die zentrale anymize App.

Die Anwendung verbindet lokale Dateien und PDF-Werkzeuge mit dem anymize Workspace. **Alle Werkzeuge einschließlich lokaler PDFs benötigen eine Anmeldung mit einem bezahlten anymize Konto und eine aktuelle Online-Prüfung.** Lokale Dateien werden nicht automatisch hochgeladen. Ein Download oder eine Dateizuordnung schaltet keine Funktionen frei.

Every tool, including local PDF, requires a signed-in paid anymize account and current online verification. Local files are not uploaded automatically. Downloading a package does not grant access.

Veröffentlichte Pakete stehen unter [Releases](https://github.com/anymize-GmbH/downloads/releases). Vorschauen werden ausdrücklich als solche gekennzeichnet. Signatur, Plattform, Version und SHA256 werden je Paket angegeben; Prüfsummen ersetzen keine Herausgebersignatur.

Dieses Repository enthält die Downloadseite und Werkzeuge zur Prüfung der ausgelieferten Pakete. Der Anwendungscode bleibt privat. Es enthält keine Zugangsdaten oder Nutzerdokumente.

Die Android-Betriebssystemprüfung verwendet frische beschleunigte Emulatoren. Ein bestandener OS-Test ist keine angemeldete Produkt-, physische Geräte- oder Store-Abnahme.

Ein bestätigter nativer Anmeldeeinstieg oder die Ablehnung anonymer Dateiöffnungen belegt noch keine vollständige Nutzung mit bezahltem Konto. Die Vorschauseite bestätigt lokale PDF-Funktionen, Standard-Dateizuordnung und native Anmeldung erst nach deren tatsächlicher Abnahme mit bezahltem Konto. Signierung und Store-Freigaben bleiben getrennte Nachweise.
