# Synthetic Android fixture

This tiny public helper is built only on a fresh disposable emulator runner. It contains a generated one-page PDF with two colored markers and a known search phrase. Its non-exported, read-only provider grants the unchanged production application one explicit content URI. The helper's own test-only debug flag permits a synthetic saved PDF to be copied into its private fixture folder for a fresh relaunch grant. It does not change the application's manifest, JavaScript, WebView debugging policy or account state.

The smoke captures actual UIAutomator XML, complete screenshot pixels, native Save As output and installed application bytes. It proves only the listed local operations and a public hosted login form. A passing form check does not prove account login, cloud chat, subscriptions or store approval.

The workflow takes five immutable selections: APK asset ID, APK SHA-256, build-info asset ID, raw build-info SHA-256 and exact application source commit. Both assets must already exist in this repository. A read-only GitHub token is available only to the fetch step. The build metadata must describe a release variant with embedded JavaScript and both arm64-v8a and x86_64 ABIs. An Expo public debug signing certificate remains a sideload preview certificate; it does not make the app a production or store release.

Each matrix job first runs the unchanged real OS baseline. The app smoke then verifies the downloaded and installed APK, actual package UID/version and signing certificate, and absence of a WebView debugging socket for the real app PID. Wi-Fi and mobile data are disabled and the absence of an active default network is observed before opening the fixture. A known phrase proves text search; two independently decoded colored pixel markers prove rendering and page rotation. Native Save As writes a real PDF into Downloads. Its bytes are inspected for the expected edit and text, then reopened through a fresh granted URI after force-stop. Networking is restored before checking the public hosted login form. Existing ANR and crash history is never cleared.

The dependency-free Node suite includes parser controls and an explicitly simulated orchestration adapter. Those simulations test the test harness and cannot establish emulator or application acceptance. Only an actual workflow result, its immutable identity, actual XML, complete PNGs and saved PDF can establish the listed runtime checks.

Run the source controls with `node --test scripts/emulator-baseline.test.mjs scripts/android-app-smoke.test.mjs`. The workflow uses `--fetch`, `--build-fixture` and `--run` in separate steps. Real execution is restricted to an ephemeral GitHub-hosted Linux runner and `emulator-5554`; it never operates a personal phone or an existing user account.

A separate source job runs on pushes affecting these public test files and on manual dispatch. It anonymously fetches the exact public workflow commit, runs the controls, then uses `--compile-helper` with pinned Java 17, Android platform 35 and build-tools 37. It needs no application APK, private repository, secret, token or emulator. Successful compiler, D8, aapt2, package and signature receipts are retained along with the synthetic helper APK. Failures retain the actual failed phase and compiler error. The three real emulator jobs run only on manual dispatch after this source job succeeds.

Two additional actual native cases produce `native-edge-result.json` and separately named XML/PNG receipts. The first starts a new process with PDF A, opens distinct searchable PDF B, sends HOME and resumes the existing app, then requires B and exactly one A/B entry in the hub. The second grants a provider URI whose binder-side `openFile` genuinely stalls and honors its cancellation signal. A visible timeout must arrive after at least 28 seconds and no later than 45 seconds; B must remain searchable/rendered, and a subsequent valid grant must open again. The original eight main stage names and all OS/ANR checks stay unchanged. Simulation regressions reject the old A replay, an instant unrelated provider error, an excessive stall and lost recovery; these source tests do not replace actual emulator evidence.
